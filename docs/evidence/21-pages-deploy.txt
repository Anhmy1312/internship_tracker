## 6. Kiểm tra lỗi trên production

    PATCH /applications/1   body {}
      -> 400  {"error":"No field to update"}

    PATCH /applications/abc body {"status":"applied"}
      -> 400  {"error":"Invalid id"}

    DELETE /applications/999999
      -> 404  {"error":"Application not found"}

Ghi chú: PowerShell 5.1 làm mất dấu ngoặc kép khi truyền JSON trực tiếp qua
`--data-binary "..."`; lần đầu request /abc trả "Invalid JSON body" vì body bị
thành `{status:applied}`. Test lại bằng file UTF-8 (`--data-binary "@file"`)
mới ra đúng "Invalid id".

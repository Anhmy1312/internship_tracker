## 2. Tạo SSH key (10 phút — làm ngay, đừng để 16/11)

Trong PowerShell:

```powershell
ssh-keygen -t ed25519 -a 100 -C "internship-tracker-infra" -f "$env:USERPROFILE\.ssh\id_ed25519_it"
```

- Passphrase: **đặt** (10–20 ký tự), lưu vào Bitwarden. Không đặt cũng được nhưng phải biết vì sao.
- Sinh ra 2 file: `id_ed25519_it` (private — **không gửi ai**) và `id_ed25519_it.pub` (public — gửi được).

Xem public key và copy vào clipboard:

```powershell
Get-Content "$env:USERPROFILE\.ssh\id_ed25519_it.pub" | Set-Clipboard
Get-Content "$env:USERPROFILE\.ssh\id_ed25519_it.pub"
```

Sửa quyền file private (Windows OpenSSH rất hay báo `UNPROTECTED PRIVATE KEY FILE`):

```powershell
icacls "$env:USERPROFILE\.ssh\id_ed25519_it" /inheritance:r /grant:r "$($env:USERNAME):(R)"
```

Tạo file `C:\Users\PC\.ssh\config` (VS Code mở được, hoặc `notepad $env:USERPROFILE\.ssh\config`) — **điền IP sau khi có VPS**:

```text
Host it-staging
    HostName 203.0.113.10
    User deploy
    IdentityFile ~/.ssh/id_ed25519_it
    ServerAliveInterval 30
    ServerAliveCountMax 3
```

Sau đó chỉ cần gõ `ssh it-staging` thay vì `ssh -i ... deploy@IP`. VS Code Remote-SSH cũng đọc file này.

Tùy chọn — dùng ssh-agent để không nhập passphrase nhiều lần:

```powershell
Get-Service ssh-agent | Set-Service -StartupType Automatic
Start-Service ssh-agent
ssh-add "$env:USERPROFILE\.ssh\id_ed25519_it"
```

## 5. Bẫy riêng của từng provider (đọc trước khi tạo máy)

| Provider | Bẫy | Cách xử lý |
|---|---|---|
| **Azure for Students** (đang dùng) | B-series (`B1s`, `B2ats_v2`…) báo `NotAvailableForSubscription` ở **Southeast Asia** | đổi region sang **East Asia**; nếu vẫn trống thì `Microsoft.Compute` chưa `Registered` (Subscriptions → Resource providers → Register) |
| Azure | Quên **NSG** → `curl` timeout dù `ufw` đã mở | Portal → VM → Networking → Inbound port rules: 22, 80, 443 |
| Azure | `Stop` thường vẫn tính tiền CPU/RAM | luôn chọn **Stop (Deallocate)**; Public IP tĩnh + disk vẫn giữ ~$6/tháng |
| **Oracle Always Free** | Ubuntu image có sẵn `iptables` chặn 80/443, **kể cả khi `ufw` đã mở** | thêm rule iptables + `netfilter-persistent save`; **và** mở ingress 80/443 trong VCN Security List |
| Oracle | ARM A1 hay báo "out of capacity" | đổi Availability Domain, hoặc dùng `VM.Standard.E2.1.Micro` (AMD, luôn có) |
| Oracle | user mặc định là `ubuntu`, không phải `root` | `ssh ubuntu@IP`, dùng `sudo` |
| DigitalOcean | không có cloud firewall mặc định → `ufw` là lớp duy nhất | giữ đúng 22/80/443, không mở 3000 |
| DigitalOcean | droplet tạo xong mới thêm SSH key thì phải rebuild | thêm key **lúc tạo** (hoặc dùng `ssh-copy-id`) |
| Hetzner | có thể yêu cầu xác minh ID | chuẩn bị CCCD/hộ chiếu, có thể chờ vài giờ |
| Mọi provider | tạo máy ở region xa → TLS/RTT chậm, demo lê | East Asia (HK) ~30–50 ms từ VN là ổn |

Ghi ngay khi tạo máy (để 16/11 không quên): **provider, region, IP, spec, image, ngày tạo, console URL**.
